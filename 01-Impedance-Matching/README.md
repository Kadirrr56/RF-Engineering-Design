
Bu dosya, Proje 1 kapsamında hazırlanan L-Network empedans eşleştirme devresinin orijinal Ansoft Designer (.adsn) projesidir. 1 GHz frekansında, 50 ohm kaynak ile 25+j30 ohm karmaşık yük arasındaki eşleştirme ağının (shunt kapasitör ve seri endüktör) simülasyon kurulumunu ve S11 parametre analizini içerir.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

This file is the original Ansoft Designer (.adsn) project for the L-Network impedance matching circuit prepared under Project 1. It includes the simulation setup and S11 parameter analysis of the matching network (shunt capacitor and series inductor) between a 50 ohm source and a 25+j30 ohm complex load at 1 GHz frequency.
